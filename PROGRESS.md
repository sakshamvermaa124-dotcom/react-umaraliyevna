# Week 1 — Components & Props

## Components

Components are reusable building blocks of a React application. They allow developers to divide the user interface into smaller, independent, and reusable parts. Each component can contain its own JSX, logic, and styling.

## Props

Props (properties) are used to pass data from a parent component to a child component. Props can contain different types of data, including strings, numbers, objects, arrays, and functions. Props are read-only, so a child component should not directly modify the props it receives.

## Key Takeaways

- Components make React applications modular and reusable.
- Props allow data to be passed from parent components to child components.
- Props are read-only.
- Components can receive multiple props.
- Components and props are fundamental concepts in React.
